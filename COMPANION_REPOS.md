# Proposed Helper Packages

Helper packages for Python, R, and Julia are proposals. This repository does not provide released packages or confirmed installation commands. Data can currently be retrieved from [AIML-SIG/pmx_benchmarks](https://github.com/AIML-SIG/pmx_benchmarks) using Git LFS.

## Possible features

- List benchmarks and their declared tasks
- Download and cache data files with integrity checks
- Read train/test splits, metadata, and YAML data dictionaries
- Record dataset versions so analyses can be reproduced

Package names, APIs, repositories, and release plans should be agreed before they are advertised as available. These helpers would provide data access; an agent evaluation framework is outside this repository's scope.

## Contribute

[Open an issue](https://github.com/AIML-SIG/pmx_benchmarks/issues/new) to propose or help build a package. Explain which language you use and which data-access features would be useful.
